# CCTV Shop Website

A modern, responsive CCTV shop website designed to showcase security cameras, CCTV systems, accessories, and related services.

## About the Project

The CCTV Shop Website helps customers explore CCTV products and learn about available security installation services. Customers can search for products, filter products by category, and use WhatsApp inquiry buttons to contact the shop.

## Features

- **Responsive Design** – Works on desktop, tablet, and mobile devices.
- **Product Showcase** – Displays CCTV cameras, recording systems, and accessories.
- **Product Search** – Allows users to search for products.
- **Category Filter** – Filters products by category.
- **WhatsApp Integration** – Allows customers to inquire about products through WhatsApp.
- **Services Section** – Displays available CCTV-related services.
- **Modern UI** – Clean layout with a professional security-themed design.
